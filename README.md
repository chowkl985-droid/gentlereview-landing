# GentleReview AI — Landing Page

Public landing page for [GentleReview AI](https://chowkl.gumroad.com/l/GentleReview), an AI-powered review reply tool for Amazon & Shopify sellers.

## Deploy

Push to `main` branch, enable GitHub Pages in repo Settings → Pages → Source: `Deploy from a branch` → `main` → `/ (root)`.
